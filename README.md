# config_collector

Configuration File Collector for devices with non-standard (SSH, SNMP) methods of configuration file export. (e.g. Web Interface Only.)

Scripts to collect configuration backups from network devices (Aruba Instant ON, Cisco, etc.).

This repository includes a Python implementation of the Aruba Instant ON 1930 backup script.

Original Perl implementation by Dariusz Zielinski-Kolasinski: https://github.com/dkolasinski/aruba-instant-on-1930-backup-script

## Requirements

Install dependencies with:

```bash
python -m pip install -r requirements.txt
```
